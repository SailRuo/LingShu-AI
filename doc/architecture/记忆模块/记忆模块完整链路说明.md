    MATCH (seed:Fact)-[r:RELATED_TO]-(related:Fact)

#### 图谱排序公式 `computeAdaptiveGraphScore()`

**文件**：`lingshu-core/src/main/java/com/lingshu/ai/core/service/impl/MemoryServiceImpl.java#L974-L990`

```java
protected double computeAdaptiveGraphScore(FactNode fact, int hop, double relationWeight) {
    double score = fact.getImportance() * 0.55
            + effectiveConfidenceForAdaptiveRanking(fact) * 0.30
            + Math.max(0.0, relationWeight) * 0.15;
    score += computeMemoryStateBonus(fact);

    // 惩罚项
    if (fact.getStatus() != null && "superseded".equalsIgnoreCase(fact.getStatus())) {
        score *= 0.35;
    }
    if (fact.getObservedAt() != null && Duration.between(fact.getObservedAt(), now).toDays() > 90) {
        score *= 0.7;
    }
    if (hop >= 2) {
        score *= 0.75;
    }
    return score;
}
```

**公式解释**：

| 权重因子 | 系数 | 说明 |
|----------|------|------|
| `importance` | × 0.55 | 事实重要性 |
| `effectiveConfidence` | × 0.30 | 置信度（fallback 到 `importance + 0.08`） |
| `relationWeight` | × 0.15 | 关系权重（来自 `RELATED_TO` 边） |
| `stateBonus` | + | 阶段三状态加分 |

**惩罚项**：

| 条件 | 惩罚系数 |
|------|----------|
| `superseded` 状态 | ×0.35 |
| 90天前陈旧事实 | ×0.7 |
| 二跳扩展 | ×0.75 |

### 2.4 Step 3: 路由决策 `calculateGainV2()`

**文件**：`lingshu-core/src/main/java/com/lingshu/ai/core/service/impl/MemoryServiceImpl.java#L1020-L1050`

#### Gain 公式

```java
protected double calculateGainV2(List<String> entities, List<GraphRetrievalHit> activatedFacts) {
    double entityRatio = (double) matchedEntities.size() / entities.size();
    double avgImportance = totalImportance / activatedFacts.size();
    return Math.min(1.0, entityRatio * 0.6 + avgImportance * 0.4);
}
```

```
gain = min(1.0, 实体匹配率 × 0.6 + 平均重要性 × 0.4)
```

#### 三种路由结果

| 条件 | 路由决策 | 向量检索 | 日志 |
|------|----------|----------|------|
| gain ≥ 0.3 | GRAPH_PRIORITIZED_VECTOR_SUPPLEMENT | ✅ 执行 | "图谱增益 >= 阈值，执行图谱优先+向量补召回" |
| gain < 0.3 但图谱非空 | GRAPH_ONLY | ❌ 跳过 | "图谱增益 < 阈值，但图谱已有结果，直接返回" |
| gain < 0.3 且图谱为空 | VECTOR_BACKUP | ✅ 执行 | "图谱无结果，执行向量兜底" |

private boolean isDirectlySupported(RetrievalFactCandidate fact, String assistantResponse) {
    String normalizedResponse = normalize(assistantResponse);
    for (String candidate : directMatchCandidates(fact.getContent())) {
        if (candidate.length() >= 4 && normalizedResponse.contains(candidate)) {
            return true;
        }
    }
    return false;
}

### 5.1 事实分数更新

**文件**：`lingshu-core/src/main/java/com/lingshu/ai/core/service/impl/AdaptiveMemoryScorerImpl.java#L23-45`

```java
public FactDelta scoreFact(double currentImportance,
                          double currentConfidence,
                          RetrievalFeedbackResult.FactFeedback feedback) {
    if (Boolean.TRUE.equals(feedback.getValid())) {
        return new FactDelta(
            clamp(currentImportance + 0.03, 0.12, 0.98),
            clamp(currentConfidence + 0.02, 0.20, 0.98)
        );
    }

    if (feedback.getConfidence() >= 0.80) {  // 高置信无效
        return new FactDelta(
            clamp(currentImportance - 0.02, 0.12, 0.98),
            clamp(currentConfidence - 0.03, 0.20, 0.98)
        );
    }

    return new FactDelta(currentImportance, currentConfidence);  // 低置信不更新
}
```

**更新策略表**：

| 反馈类型 | importance | confidence | 条件 |
|----------|-----------|------------|------|
| `valid=true` | +0.03 | +0.02 | 无条件 |
| `valid=false` | -0.02 | -0.03 | confidence ≥ 0.80 |
| 低置信/不确定 | 不变 | 不变 | confidence < 0.80 |

**边界 clamp**：

| 字段 | 最小值 | 最大值 |
|------|--------|--------|
| importance | 0.12 | 0.98 |
| confidence | 0.20 | 0.98 |

### 7.2 状态写回 `applyMemoryStateUpdates()`

```java
if (!memoryStateWriteEnabled) { return 0; }

// 高置信 supported → 更新向量
if (Boolean.TRUE.equals(feedback.getValid()) && isHighConfidence(feedback.getConfidence())) {
    MemoryStateUpdater.MemoryStateDelta delta = memoryStateUpdater.applySupported(
        record.getTaskVector(),
        record.getTaskUncertainty(),
        record.getUpdateCount(),
        queryVector,
        feedback.getConfidence()
    );
    record.setTaskVector(delta.serializedVector());
    record.setTaskUncertainty(delta.uncertainty());
    record.setUpdateCount(delta.updateCount());
}

// unsupported → 增加不确定性
if (Boolean.FALSE.equals(feedback.getValid())) {
    double uncertainty = memoryStateUpdater.applyUnsupportedUncertainty(
        record.getTaskUncertainty(),
        feedback.getConfidence()
    );
    record.setTaskUncertainty(uncertainty);
}
```

### 7.3 状态读取（排序加分）`computeMemoryStateBonus()`

**文件**：`lingshu-core/src/main/java/com/lingshu/ai/core/service/impl/MemoryServiceImpl.java#L1007-L1035`

```java
private double computeMemoryStateBonus(FactNode fact) {
    if (!memoryStateReadEnabled) return 0;

    double[] queryVector = stateBonusQueryVector.get();
    MemoryStateRecord record = memoryStateRecordRepository.findByFactId(fact.getId());

    return memoryStateProjector.computeStateBonus(
        record.getTaskVector(),
        record.getTaskUncertainty(),
        queryVector,
        MEMORY_STATE_BONUS_ALPHA  // 0.12
    );
}
```

**加分公式**：
```java
bonus = alpha × uncertainty_factor × cosine_similarity(taskVector, queryVector)
```
